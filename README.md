HTML

HTML digunakan untuk membuat struktur halaman program, seperti judul, kolom input nama barang, harga, jumlah barang, tombol hitung, dan tempat menampilkan hasil.

2. CSS

CSS digunakan untuk mengatur tampilan program agar lebih menarik. Saya menggunakan tema warna pink supaya tampilannya lebih estetik, rapi, dan nyaman dilihat.

3. JavaScript

JavaScript digunakan untuk menjalankan fungsi program, seperti menghitung total belanja dan menentukan diskon. Program ini menggunakan percabangan if, else if, dan else untuk menentukan diskon berdasarkan total belanja.

Selain itu, terdapat perulangan for untuk menampilkan daftar barang dan while untuk menghitung jumlah barang.

Kesimpulan

Program ini dibuat untuk menghitung diskon belanja secara otomatis. Dari program ini, saya belajar menerapkan HTML, CSS, JavaScript, percabangan, dan perulangan dalam sebuah website sederhana.
